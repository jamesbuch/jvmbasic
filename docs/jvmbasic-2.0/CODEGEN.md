# JVM BASIC 2.0 Code Generation Guide

This document explains how bytecode is generated in JVM BASIC 2.0.

## Current Architecture (MVP)

```
Source Code (.jvmb)
       │
       ▼
   ANTLR Lexer/Parser
       │
       ▼
   Parse Tree (CST)
       │
       ├─────────────────────────────────────────┐
       │                                         │
       ▼                                         ▼
 CompilerVisitor                          IRBuilder (debug only)
 (ASM bytecode)                                  │
       │                                         ▼
       ▼                                   Tree IR (-ir flag)
   .class file                                   │
                                                 ▼
                                           IRLowering
                                                 │
                                                 ▼
                                           Stack IR (-sir flag)
```

**Important**: In the current MVP, we generate bytecode **directly from the ANTLR parse tree** using the `CompilerVisitor`. The IR representations (Tree IR and Stack IR) are for **debugging and visualization only** - they are NOT used in code generation.

## Why Visitor-Based Codegen for MVP?

1. **Simplicity**: Direct mapping from parse tree to bytecode
2. **Fast iteration**: No need to maintain IR → bytecode mapping
3. **Proven approach**: Many compilers start this way
4. **Working now**: We have real programs compiling and running

## Future Architecture (Post-MVP)

For optimization and better code quality, we plan to:
1. Generate Stack IR (SIR) from the parse tree
2. Run optimization passes on SIR
3. Generate bytecode from SIR

But that's for later. The MVP works now.

## How Code Generation Works

### Compilation Pipeline

```java
// Main.java - compile() method

// 1. Parse source file
JvmBasicParser.CompilationUnitContext tree = parser.compilationUnit();

// 2. Collect symbols (pass 1)
SymbolCollector symbolCollector = new SymbolCollector();
ParseTreeWalker walker = new ParseTreeWalker();
walker.walk(symbolCollector, tree);

// 3. Generate bytecode (pass 2)
CompilerVisitor visitor = new CompilerVisitor(outputName, symbolCollector.getSymbols());
visitor.visit(tree);

// 4. Write class file
byte[] bytecode = visitor.getBytecode();
Files.write(Path.of(outputName + ".class"), bytecode);
```

### CompilerVisitor Structure

The `CompilerVisitor` extends ANTLR's `JvmBasicParserBaseVisitor<Object>` and uses ASM to emit bytecode.

```java
public class CompilerVisitor extends JvmBasicParserBaseVisitor<Object> {
    private ClassWriter cw;      // ASM class writer
    private MethodVisitor mv;    // Current method being generated
    private String currentMethod; // "main" or function name
    private int localVarSlot;    // Next available local variable slot

    // Track variables in main method
    private final Map<String, LocalVar> mainLocals = new LinkedHashMap<>();

    // Track expression type for println overload selection
    private String lastExprType = "Object";
}
```

## Bytecode Generation Examples

### Example 1: Variable Declaration

**Source:**
```basic
var x as Integer = 10
```

**Generated Bytecode:**
```
LDC 10           ; Push constant 10
ISTORE 1         ; Store in local slot 1 (slot 0 = args in main)
```

**Visitor Code:**
```java
@Override
public Object visitVarStatement(JvmBasicParser.VarStatementContext ctx) {
    String name = ctx.IDENTIFIER().getText();
    String type = getTypeName(ctx.typeName());

    // Evaluate initializer
    if (ctx.expression() != null) {
        visit(ctx.expression());
    } else {
        generateDefaultValue(type);
    }

    // Allocate slot and store
    int slot = localVarSlot++;
    storeLocal(slot, type);

    // Track for later use
    if ("main".equals(currentMethod)) {
        mainLocals.put(name, new LocalVar(name, type, slot));
    }
    return null;
}
```

### Example 2: Arithmetic Expression

**Source:**
```basic
var z as Integer = x + y
```

**Generated Bytecode:**
```
ILOAD 1          ; Load x from slot 1
ILOAD 2          ; Load y from slot 2
IADD             ; Add them
ISTORE 3         ; Store result in slot 3
```

**Visitor Code:**
```java
@Override
public Object visitAdditiveExpression(JvmBasicParser.AdditiveExpressionContext ctx) {
    // First operand
    visit(ctx.multiplicativeExpression(0));

    // Process additional operands
    for (int i = 1; i < ctx.multiplicativeExpression().size(); i++) {
        visit(ctx.multiplicativeExpression(i));
        String op = ctx.getChild(2 * i - 1).getText();
        switch (op) {
            case "+" -> mv.visitInsn(IADD);
            case "-" -> mv.visitInsn(ISUB);
        }
    }
    return null;
}
```

### Example 3: Console.WriteLine

**Source:**
```basic
Console.WriteLine("Hello")
Console.WriteLine(42)
```

**Generated Bytecode (String):**
```
GETSTATIC java/lang/System.out : Ljava/io/PrintStream;
LDC "Hello"
INVOKEVIRTUAL java/io/PrintStream.println(Ljava/lang/String;)V
```

**Generated Bytecode (Integer):**
```
GETSTATIC java/lang/System.out : Ljava/io/PrintStream;
BIPUSH 42
INVOKEVIRTUAL java/io/PrintStream.println(I)V
```

**Key insight**: We track `lastExprType` to select the correct `println` overload.

**Visitor Code:**
```java
private void handleMethodInvocation(String methodName, ArgumentListContext argList) {
    if ("Console".equalsIgnoreCase(pendingNamespace)) {
        if ("WriteLine".equalsIgnoreCase(methodName)) {
            mv.visitFieldInsn(GETSTATIC, "java/lang/System", "out",
                             "Ljava/io/PrintStream;");
            if (argList != null && !argList.argument().isEmpty()) {
                visit(argList.argument(0).expression());
                emitPrintln();  // Uses lastExprType
            } else {
                mv.visitMethodInsn(INVOKEVIRTUAL, "java/io/PrintStream",
                                  "println", "()V", false);
            }
        }
    }
}

private void emitPrintln() {
    String descriptor = switch (lastExprType) {
        case "Integer", "int" -> "(I)V";
        case "Long", "long" -> "(J)V";
        case "Float", "float" -> "(F)V";
        case "Double", "double" -> "(D)V";
        case "Boolean", "boolean" -> "(Z)V";
        case "String" -> "(Ljava/lang/String;)V";
        default -> "(Ljava/lang/Object;)V";
    };
    mv.visitMethodInsn(INVOKEVIRTUAL, "java/io/PrintStream", "println",
                      descriptor, false);
}
```

### Example 4: If/Else Statement

**Source:**
```basic
if x > 5 then
    Console.WriteLine("Greater")
else
    Console.WriteLine("Not greater")
end if
```

**Generated Bytecode:**
```
ILOAD 1              ; Load x
ICONST_5             ; Push 5
IF_ICMPLE else_label ; If x <= 5, jump to else
  ; Then block
  GETSTATIC System.out
  LDC "Greater"
  INVOKEVIRTUAL println
  GOTO end_label
else_label:
  ; Else block
  GETSTATIC System.out
  LDC "Not greater"
  INVOKEVIRTUAL println
end_label:
```

**Visitor Code:**
```java
@Override
public Object visitIfStatement(JvmBasicParser.IfStatementContext ctx) {
    Label elseLabel = new Label();
    Label endLabel = new Label();

    // Evaluate condition (leaves 0 or 1 on stack)
    visit(ctx.expression());
    mv.visitJumpInsn(IFEQ, elseLabel);  // Jump if false (0)

    // Then block
    for (var stmt : ctx.statement()) {
        visit(stmt);
    }
    mv.visitJumpInsn(GOTO, endLabel);

    // Else block
    mv.visitLabel(elseLabel);
    if (ctx.elseClause() != null) {
        for (var stmt : ctx.elseClause().statement()) {
            visit(stmt);
        }
    }

    mv.visitLabel(endLabel);
    return null;
}
```

### Example 5: While Loop

**Source:**
```basic
var i as Integer = 0
while i < 5
    Console.WriteLine(i)
    i = i + 1
end while
```

**Generated Bytecode:**
```
ICONST_0
ISTORE 1           ; i = 0

start_label:
ILOAD 1            ; Load i
ICONST_5           ; Push 5
IF_ICMPGE end_label ; If i >= 5, exit loop

  ; Loop body
  GETSTATIC System.out
  ILOAD 1
  INVOKEVIRTUAL println(I)V

  ILOAD 1          ; i + 1
  ICONST_1
  IADD
  ISTORE 1         ; i = i + 1

  GOTO start_label

end_label:
```

**Visitor Code:**
```java
@Override
public Object visitWhileStatement(JvmBasicParser.WhileStatementContext ctx) {
    Label startLabel = new Label();
    Label endLabel = new Label();

    mv.visitLabel(startLabel);

    // Evaluate condition
    visit(ctx.expression());
    mv.visitJumpInsn(IFEQ, endLabel);  // Exit if condition is false

    // Loop body
    for (var stmt : ctx.statement()) {
        visit(stmt);
    }

    mv.visitJumpInsn(GOTO, startLabel);
    mv.visitLabel(endLabel);

    return null;
}
```

### Example 6: Comparison Operators

**Source:**
```basic
if x < 5 then ...
```

**Generated Bytecode:**
```
ILOAD 1              ; Load x
ICONST_5             ; Push 5
IF_ICMPLT true_label ; Jump if x < 5
ICONST_0             ; Push false (0)
GOTO end_label
true_label:
ICONST_1             ; Push true (1)
end_label:
```

**Visitor Code:**
```java
@Override
public Object visitRelationalExpression(JvmBasicParser.RelationalExpressionContext ctx) {
    if (ctx.shiftExpression().size() == 1) {
        return visit(ctx.shiftExpression(0));
    }

    visit(ctx.shiftExpression(0));
    for (int i = 1; i < ctx.shiftExpression().size(); i++) {
        visit(ctx.shiftExpression(i));
        String op = ctx.getChild(2 * i - 1).getText();

        Label trueLabel = new Label();
        Label endLabel = new Label();

        switch (op) {
            case "<" -> mv.visitJumpInsn(IF_ICMPLT, trueLabel);
            case ">" -> mv.visitJumpInsn(IF_ICMPGT, trueLabel);
            case "<=" -> mv.visitJumpInsn(IF_ICMPLE, trueLabel);
            case ">=" -> mv.visitJumpInsn(IF_ICMPGE, trueLabel);
        }
        mv.visitInsn(ICONST_0);
        mv.visitJumpInsn(GOTO, endLabel);
        mv.visitLabel(trueLabel);
        mv.visitInsn(ICONST_1);
        mv.visitLabel(endLabel);
    }
    return null;
}
```

## Key ASM Patterns

### Class Structure
```java
cw = new ClassWriter(ClassWriter.COMPUTE_FRAMES | ClassWriter.COMPUTE_MAXS);
cw.visit(V21, ACC_PUBLIC | ACC_SUPER, className, null, "java/lang/Object", null);

// Constructor
mv = cw.visitMethod(ACC_PUBLIC, "<init>", "()V", null, null);
mv.visitCode();
mv.visitVarInsn(ALOAD, 0);
mv.visitMethodInsn(INVOKESPECIAL, "java/lang/Object", "<init>", "()V", false);
mv.visitInsn(RETURN);
mv.visitMaxs(1, 1);
mv.visitEnd();

// Main method
mv = cw.visitMethod(ACC_PUBLIC | ACC_STATIC, "main", "([Ljava/lang/String;)V", null, null);
// ... code ...
mv.visitInsn(RETURN);
mv.visitMaxs(0, 0);  // COMPUTE_MAXS calculates these
mv.visitEnd();

cw.visitEnd();
byte[] bytecode = cw.toByteArray();
```

### Local Variable Slots
- In `main`: slot 0 = `String[] args`
- In instance methods: slot 0 = `this`
- Variables are assigned incrementally: slot 1, 2, 3...
- `long` and `double` take 2 slots

### Type Descriptors
| BASIC Type | JVM Descriptor | Load | Store |
|------------|----------------|------|-------|
| Integer    | I              | ILOAD | ISTORE |
| Long       | J              | LLOAD | LSTORE |
| Float      | F              | FLOAD | FSTORE |
| Double     | D              | DLOAD | DSTORE |
| Boolean    | Z              | ILOAD | ISTORE |
| String     | Ljava/lang/String; | ALOAD | ASTORE |

## What's Working Now

| Feature | Status | Notes |
|---------|--------|-------|
| Integer variables | ✅ | var x as Integer = 5 |
| Arithmetic (+,-,*,/) | ✅ | Basic integer ops |
| Console.WriteLine | ✅ | Strings and integers |
| If/Then/Else | ✅ | With comparison operators |
| While loops | ✅ | With variable assignment |
| Comparisons (<,>,<=,>=,=,<>) | ✅ | Integer comparisons |

## What's Not Yet Implemented

| Feature | Priority | Notes |
|---------|----------|-------|
| For loops | High | Need to track loop variable |
| User functions | High | Need to handle parameters |
| String operations | Medium | Concatenation, methods |
| Other types (Long, Float, Double) | Medium | Need type inference |
| Arrays | Medium | Need bounds checking |
| Classes | Low | Complex |

## Adding New Features

### Checklist for Adding a New Statement Type

1. **Grammar**: Ensure it parses correctly (check with `-tree` flag)
2. **Visitor method**: Add `visitXxxStatement()` in CompilerVisitor
3. **Test**: Create a simple test program
4. **Document**: Add example to this file

### Example: Adding For Loop

```java
@Override
public Object visitForStatement(JvmBasicParser.ForStatementContext ctx) {
    String varName = ctx.IDENTIFIER().getText();

    // Initialize loop variable
    visit(ctx.expression(0));  // Start value
    int slot = localVarSlot++;
    mv.visitVarInsn(ISTORE, slot);
    mainLocals.put(varName, new LocalVar(varName, "Integer", slot));

    Label startLabel = new Label();
    Label endLabel = new Label();

    mv.visitLabel(startLabel);

    // Check condition: i <= end
    mv.visitVarInsn(ILOAD, slot);
    visit(ctx.expression(1));  // End value
    mv.visitJumpInsn(IF_ICMPGT, endLabel);

    // Loop body
    for (var stmt : ctx.statement()) {
        visit(stmt);
    }

    // Increment
    mv.visitVarInsn(ILOAD, slot);
    mv.visitInsn(ICONST_1);
    mv.visitInsn(IADD);
    mv.visitVarInsn(ISTORE, slot);

    mv.visitJumpInsn(GOTO, startLabel);
    mv.visitLabel(endLabel);

    return null;
}
```

## Future: IR-Based Code Generation

When we move to IR-based codegen:

1. **Build IR from parse tree** (already done - IRBuilder)
2. **Lower Tree IR to Stack IR** (already done - IRLowering)
3. **Emit bytecode from Stack IR** (TODO)

The Stack IR is already close to JVM bytecode:
```
%0 = ICONST 10
%1 = ICONST 25
%2 = IADD %0, %1
ISTORE local_0, %2
```

Mapping to bytecode is straightforward:
```
BIPUSH 10
BIPUSH 25
IADD
ISTORE 1
```

Benefits of IR-based codegen:
- Optimization passes (constant folding, dead code elimination)
- Better register allocation
- Easier to target multiple backends
